1. Product Overview
1.1 Vision
An open, extensible web platform where multiple specialized AI agents collaborate to complete complex research and discovery tasks. The full stack runs on JavaScript/TypeScript — React frontend, Node.js backend — and must be deployable, runnable, and demonstrable without spending any money.
1.2 Core Constraint — “Free Forever”
Category
Constraint
LLM inference
Must use providers with permanent free tiers or local models via Ollama
Search
Must use free search APIs or self-hosted meta-search
Vector storage
Must use embedded / self-hosted open-source DB with a Node.js client
Embeddings
Must use open-source models via @xenova/transformers (runs in Node) or free API
Hosting
Frontend on Vercel/Netlify free tier; backend on Render/Railway free tier
Scraping
Must use free scraping libraries (cheerio, puppeteer headless)
1.3 Target Users

Builders who want a working multi-agent web app without an API budget.


Researchers who need automated web research at zero marginal cost.


Learners who want to inspect a full-stack AI pipeline (React → Node → LLM → tools).

3.2 Reliability

Pipeline must not crash if one agent fails; return partial results with an error field.


LLM provider failover must be automatic (Groq → Cerebras → Gemini → Ollama).


All external calls must have timeouts (search: 10s, scrape: 8s, LLM: 60s).


SSE connection must auto-reconnect with exponential backoff on the client.

3.3 Security

Scraper must reject private / loopback IPs (SSRF guard).


API keys must never be logged or committed; use .env and hosting platform secrets.


All LLM output rendered in the browser must be sanitized (DOMPurify).


CORS must be configured to allow only the frontend origin.

3.4 Portability

Backend must run on Node.js 18+ (LTS) with no native compilation required.


Frontend must build to static assets deployable on any CDN.


Must not depend on any paid service at runtime.


Must run inside Render free tier (512 MB RAM).

6. Acceptance Criteria

A user can enter a topic in the React frontend and receive a structured Markdown report.


The pipeline runs end-to-end using only free-tier APIs and local components.


If Groq is rate-limited, the system automatically falls back to Cerebras or Gemini without user intervention.


The frontend shows live step status (waiting → running → done) via SSE.


Raw outputs are viewable in expanders; the final report is downloadable as .md and .json.


No paid service is contacted at any point.


Frontend deploys to Vercel; backend deploys to Render — both free tier.


The full pipeline completes in under 2 minutes on free tiers.
