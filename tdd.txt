3.2 Failover Logic
typescript
const dailyCounters = new Map<ProviderName, { count: number; resetAt: number }>();export async function callLLM(  messages: OpenAI.Chat.ChatCompletionMessageParam[],  options?: { model?: string; temperature?: number }): Promise<{ content: string; provider: ProviderName; model: string }> {  const errors: string[] = [];  for (const provider of PROVIDERS) {    const apiKey = process.env[provider.apiKeyEnv];    if (!apiKey && provider.name !== "ollama") continue;    // Rate-limit check    const counter = dailyCounters.get(provider.name);    if (counter && counter.count >= provider.rpdLimit && Date.now() < counter.resetAt) {      errors.push(`${provider.name}: daily limit reached`);      continue;    }    try {      const client = new OpenAI({ apiKey: apiKey ?? "ollama", baseURL: provider.baseURL });      const response = await client.chat.completions.create({        model: options?.model ?? provider.defaultModel,        messages,        temperature: options?.temperature ?? 0.7,      });      // Increment counter      const existing = dailyCounters.get(provider.name);      dailyCounters.set(provider.name, {        count: (existing?.count ?? 0) + 1,        resetAt: existing?.resetAt ?? Date.now() + 24 * 60 * 60 * 1000,      });      return {        content: response.choices[0]?.message?.content ?? "",        provider: provider.name,        model: options?.model ?? provider.defaultModel,      };    } catch (err: any) {      errors.push(`${provider.name}: ${err.message}`);      continue;    }  }  throw new Error(`All providers failed:\n${errors.join("\n")}`);}
All four providers are OpenAI-compatible, so a single openai SDK instance with a custom baseURL works for all of them.
3.3 Rate Limit Tracking
Keep an in-memory Map per provider. Before calling, check count < rpdLimit. If exceeded, skip to next provider. Reset counters after 24 hours.

import { search, SafeSearchType } from "duck-duck-scrape";export async function webSearch(query: string): Promise<string> {  try {    const results = await search(query, {      safeSearch: SafeSearchType.MODERATE,    });    const out = results.results.slice(0, 5).map((r) =>      `Title: ${r.title}\nURL: ${r.url}\nSnippet: ${r.description.slice(0, 300)}\n`    );    return out.join("\n----\n");  } catch (err: any) {    return `Search failed: ${err.message}`;  }}
Why: DuckDuckGo requires no API key and has no daily quota. The duck-duck-scrape npm package works in Node.js 18+ with zero configuration .
Alternative: Self-host Jiro locally for 9 engines behind one free local API .
Alternative: Use SERPJET for 1,000 free searches/month, recurring, no credit card .
4.2 Scraper — Hardened
File: server/src/tools/scrape.ts
typescript
import axios from "axios";import * as cheerio from "cheerio";import { URL } from "url";import ipaddr from "ipaddr.js";function isSafeUrl(url: string): boolean {  try {    const parsed = new URL(url);    const host = parsed.hostname;    // Block private IP ranges    if (ipaddr.isValid(host)) {      const addr = ipaddr.parse(host);      const range = addr.range();      if (["private", "loopback", "linkLocal", "uniqueLocal"].includes(range)) {        return false;      }    }    // Block localhost    if (["localhost", "127.0.0.1", "::1"].includes(host)) return false;    return true;  } catch {    return false;  }}export async function scrapeUrl(url: string): Promise<string> {  if (!isSafeUrl(url)) {    return `Blocked unsafe URL: ${url}`;  }  try {    const response = await axios.get(url, {      timeout: 8000,      headers: { "User-Agent": "Mozilla/5.0" },      maxRedirects: 3,    });    const contentType = response.headers["content-type"] ?? "";    if (!contentType.includes("text/html")) {      return `Skipped non-HTML content: ${url} (${contentType})`;    }    const $ = cheerio.load(response.data);    $("script, style, nav, footer, header, aside").remove();    const text = $("body").text().replace(/\s+/g, " ").trim();    return text.slice(0, 3000);  } catch (err: any) {    return `Could not scrape URL: ${err.message}`;  }}
Changes from the original Python version: SSRF guard using ipaddr.js, raise_for_status equivalent via axios (throws on 4xx/5xx by default), content-type check, no rich.print equivalent.

5. Embeddings & Vector Store — Free
File: server/src/tools/embed.ts
5.1 Embeddings
Use @xenova/transformers with all-MiniLM-L6-v2 — runs in Node.js via ONNX runtime, CPU-friendly, no API key.
typescript
import { pipeline } from "@xenova/transformers";let embedder: any = null;async function getEmbedder() {  if (!embedder) {    embedder = await pipeline("feature-extraction", "Xenova/all-MiniLM-L6-v2");  }  return embedder;}export async function embed(text: string): Promise<number[]> {  const pipe = await getEmbedder();  const output = await pipe(text, { pooling: "mean", normalize: true });  return Array.from(output.data as Float32Array);}
Why not OpenAI embeddings: Paid. @xenova/transformers downloads the model once (~80 MB) and runs entirely in-process.
5.2 Vector Store — ChromaDB
Chroma runs in-process via the chromadb npm package — no server, no Docker, no cost. It is Apache 2.0 licensed and supports JavaScript/TypeScript .

6. Orchestrator — SSE-Based Progress Streaming
File: server/src/orchestrator/pipeline.ts
This is the key design for the React frontend. Instead of running all four steps and returning once, the pipeline emits events after each step. The backend exposes these over SSE so the React app can render live step cards.
6.1 Pipeline as an Async Generator
typescript
import type { PipelineState, StepResult } from "../schemas/pipeline.js";import { callLLM } from "../llm/router.js";import { webSearch } from "../tools/search.js";import { scrapeUrl } from "../tools/scrape.js";export async function* runResearchPipeline(  topic: string): AsyncGenerator<{ step: string; state: PipelineState }> {  const state: PipelineState = { topic, steps: {} };  // ── Step 1: Search ──  state.steps.search = { status: "running" };  yield { step: "search", state };  try {    const started = Date.now();    const searchResults = await webSearch(      `Find recent, reliable and detailed information about: ${topic}`    );    state.steps.search = {      status: "done",      output: searchResults,      durationMs: Date.now() - started,      provider: "duckduckgo",    };  } catch (err: any) {    state.steps.search = { status: "error", error: err.message };    yield { step: "search", state };    return;  }  yield { step: "search", state };  // ── Step 2: Reader ──  state.steps.reader = { status: "running" };  yield { step: "reader", state };  try {    const started = Date.now();    const readerPrompt = `Based on the following search results about '${topic}', pick the most relevant URL and scrape it for deeper content.Search Results:${(state.steps.search.output ?? "").slice(0, 800)}`;    // In a real agent, the LLM would call the scrape tool.    // For v1, extract the first URL and scrape directly.    const urlMatch = (state.steps.search.output ?? "").match(/URL:\s*(\S+)/);    const scraped = urlMatch      ? await scrapeUrl(urlMatch[1])      : "No URL found in search results.";    state.steps.reader = {      status: "done",      output: scraped,      durationMs: Date.now() - started,      provider: "local",    };  } catch (err: any) {    state.steps.reader = { status: "error", error: err.message };    yield { step: "reader", state };    return;  }  yield { step: "reader", state };  // ── Step 3: Writer ──  state.steps.writer = { status: "running" };  yield { step: "writer", state };  try {    const started = Date.now();    const research = `SEARCH RESULTS:\n${state.steps.search.output}\n\nDETAILED SCRAPED CONTENT:\n${state.steps.reader.output}`;    const result = await callLLM([      { role: "system", content: "You are a research report writer. Write a comprehensive, well-structured report." },      { role: "user", content: `Write a comprehensive research report on: ${topic}\n\nResearch:\n${research}` },    ], { temperature: 0.4 });    state.steps.writer = {      status: "done",      output: result.content,      durationMs: Date.now() - started,      provider: result.provider,      model: result.model,    };  } catch (err: any) {    state.steps.writer = { status: "error", error: err.message };    yield { step: "writer", state };    return;  }  yield { step: "writer", state };  // ── Step 4: Critic ──  state.steps.critic = { status: "running" };  yield { step: "critic", state };  try {    const started = Date.now();    const result = await callLLM([      { role: "system", content: "You are a critical reviewer. Score the report 1-10 on accuracy, depth, and clarity. Suggest specific improvements." },      { role: "user", content: `Review this report:\n\n${state.steps.writer.output}` },    ], { temperature: 0.2 });    state.steps.critic = {      status: "done",      output: result.content,      durationMs: Date.now() - started,      provider: result.provider,      model: result.model,    };  } catch (err: any) {    state.steps.critic = { status: "error", error: err.message };    yield { step: "critic", state };    return;  }  yield { step: "critic", state };}
6.2 Express Route — SSE Streaming
File: server/src/routes/runs.ts
typescript
import { Router } from "express";import { runResearchPipeline } from "../orchestrator/pipeline.js";import { runStore } from "../orchestrator/runStore.js";const router = Router();router.get("/:id/stream", async (req, res) => {  const runId = req.params.id;  const run = runStore.get(runId);  if (!run) {    return res.status(404).json({ error: "Run not found" });  }  res.writeHead(200, {    "Content-Type": "text/event-stream",    "Cache-Control": "no-cache",    Connection: "keep-alive",  });  const send = (event: string, data: any) => {    res.write(`event: ${event}\ndata: ${JSON.stringify(data)}\n\n`);  };  try {    for await (const { step, state } of runResearchPipeline(run.topic)) {      run.state = state;      send("step", { step, state });      // Checkpoint after each step      await runStore.checkpoint(runId, state);    }    send("done", { state: run.state });  } catch (err: any) {    send("error", { message: err.message });  } finally {    res.end();  }});export default router;

6.3 React Hook — SSE Consumer
File: client/src/hooks/useResearchRun.ts
typescript
import { useState, useCallback, useRef } from "react";import type { PipelineState } from "../types/pipeline";export function useResearchRun() {  const [state, setState] = useState<PipelineState | null>(null);  const [running, setRunning] = useState(false);  const [done, setDone] = useState(false);  const [error, setError] = useState<string | null>(null);  const eventSourceRef = useRef<EventSource | null>(null);  const start = useCallback(async (topic: string) => {    setRunning(true);    setDone(false);    setError(null);    setState(null);    // 1. Create the run    const createRes = await fetch(`${import.meta.env.VITE_API_URL}/api/research`, {      method: "POST",      headers: { "Content-Type": "application/json" },      body: JSON.stringify({ topic }),    });    const { runId } = await createRes.json();    // 2. Subscribe to SSE    const es = new EventSource(      `${import.meta.env.VITE_API_URL}/api/runs/${runId}/stream`    );    eventSourceRef.current = es;    es.addEventListener("step", (e) => {      const { state } = JSON.parse(e.data);      setState(state);    });    es.addEventListener("done", (e) => {      const { state } = JSON.parse(e.data);      setState(state);      setRunning(false);      setDone(true);      es.close();    });    es.addEventListener("error", (e: any) => {      setError(e.data ? JSON.parse(e.data).message : "Stream error");      setRunning(false);      es.close();    });  }, []);  const stop = useCallback(() => {    eventSourceRef.current?.close();    setRunning(false);  }, []);  return { state, running, done, error, start, stop };}
6.4 React Step Card Component
File: client/src/components/StepCard.tsx
tsx
import type { StepResult } from "../types/pipeline";interface Props {  num: string;  title: string;  step: StepResult | undefined;  desc?: string;}const statusConfig: Record<string, { label: string; className: string }> = {  waiting: { label: "WAITING", className: "status-waiting" },  running: { label: "● RUNNING", className: "status-running" },  done:    { label: "✓ DONE",   className: "status-done" },  error:   { label: "✕ ERROR",  className: "status-error" },};export function StepCard({ num, title, step, desc }: Props) {  const state = step?.status ?? "waiting";  const { label, className } = statusConfig[state];  return (    <div className={`step-card ${state === "running" ? "active" : ""} ${state === "done" ? "done" : ""}`}>      <div className="step-header">        <span className="step-num">{num}</span>        <span className="step-title">{title}</span>        <span className={`step-status ${className}`}>{label}</span>      </div>      {desc && <div className="step-desc">{desc}</div>}      {step?.error && <div className="step-error">{step.error}</div>}    </div>  );}
Key difference from Streamlit: React re-renders automatically whenever state changes. Because the SSE hook updates setState after each step event, the step cards animate between waiting → running → done without any manual st.rerun() equivalent.

7.4 Critic Chain

Provider: Cerebras llama3.3-70b (different provider, so rate limits don't collide)

Temperature: 0.2 (deterministic, critical)


Prompt: "Review this report. Score it 1–10 on accuracy, depth, and clarity. Suggest specific improvements."

Why spread across providers: Each free tier has its own rate limit. By putting the Writer on Gemini and the Critic on Cerebras, you triple your effective daily budget.

import ReactMarkdown from "react-markdown";import DOMPurify from "dompurify";export function ReportPanel({ markdown }: { markdown: string }) {  const sanitized = DOMPurify.sanitize(markdown);  return (    <div className="report-panel">      <div className="panel-label orange">📝 Final Research Report</div>      <ReactMarkdown>{sanitized}</ReactMarkdown>    </div>  );}
Why DOMPurify: Your Streamlit version had an HTML injection risk because it did f'<div>{r["search"]}</div>' with unsafe_allow_html=True. In React, react-markdown does not render raw HTML by default, and DOMPurify adds a second layer of defense.
